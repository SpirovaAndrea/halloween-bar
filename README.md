# Halloween Bar

1. `npm install && npm run dev` to test locally (open on your phone via your local IP).
2. Edit `data/cocktails.json` to change drinks. Bases/mixers are generated from it automatically.
3. Drop photos in `public/img/` using the filenames in the JSON (missing ones fall back to the emoji).
4. Push to GitHub, import the repo in Vercel, deploy. Generate the QR from the final URL.
